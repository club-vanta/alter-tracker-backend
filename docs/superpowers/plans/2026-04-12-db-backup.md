# Database Backup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an automatic PostgreSQL backup container that uploads a gzipped SQL dump to S3 every 2 hours, retained for 90 days.

**Architecture:** A custom Docker image (`postgres:18-alpine` + `aws-cli`) runs an infinite loop: `pg_dump | gzip | aws s3 cp`, then sleeps 7200 seconds. It runs as a Docker Compose service alongside the app. An S3 bucket is created by Terraform with a 90-day lifecycle rule. The container inherits IAM credentials from the EC2 instance profile (hop limit 2 already configured).

**Tech Stack:** Terraform/OpenTofu, Docker, Alpine Linux, pg_dump, aws-cli, GitHub Actions

**Files:**

- [ ] **Step 1: Create `infra/backup.tf`**

```hcl
data "aws_caller_identity" "current" {}

resource "aws_s3_bucket" "db_backups" {
  bucket = "${local.project_name}-db-backups-${data.aws_caller_identity.current.account_id}"
}

resource "aws_s3_bucket_public_access_block" "db_backups" {
  bucket = aws_s3_bucket.db_backups.id

  block_public_acls       = true
  block_public_policy     = true
  ignore_public_acls      = true
  restrict_public_buckets = true
}

resource "aws_s3_bucket_lifecycle_configuration" "db_backups" {
  bucket = aws_s3_bucket.db_backups.id

  rule {
    id     = "expire-old-backups"
    status = "Enabled"

    filter {}

    expiration {
      days = 90
    }
  }
}

resource "aws_iam_role_policy" "s3_backup_write" {
  name = "${local.project_name}-s3-backup-write"
  role = aws_iam_role.ec2_ssm_role.id

  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [{
      Effect   = "Allow"
      Action   = "s3:PutObject"
      Resource = "${aws_s3_bucket.db_backups.arn}/*"
    }]
  })
}
```

### Task 2: Backup Docker image

**Files:**
- Create: `docker/backup/Dockerfile`
- Create: `docker/backup/backup.sh`

- [ ] **Step 1: Create `docker/backup/backup.sh`**

```sh
#!/bin/sh
set -e

echo "Backup service started. Running every 2 hours."

while true; do
  FILENAME="backup-$(date +%Y%m%d_%H%M%S).sql.gz"
  echo "Starting backup: ${FILENAME}"

  if pg_dump "${DATABASE_URL}" | gzip | aws s3 cp - "s3://${BACKUP_BUCKET}/${FILENAME}"; then
    echo "Backup complete: ${FILENAME}"
  else
    echo "Backup FAILED: ${FILENAME}" >&2
  fi

  sleep 7200
done
```

- [ ] **Step 2: Create `docker/backup/Dockerfile`**

```dockerfile
FROM postgres:18-alpine
RUN apk add --no-cache aws-cli
COPY backup.sh /backup.sh
RUN chmod +x /backup.sh
ENTRYPOINT ["/backup.sh"]
```

### Task 3: Add backup service to docker-compose.yml

**Files:**
- Modify: `docker-compose.yml`

- [ ] **Step 1: Add the `backup` service**

Add the following to `docker-compose.yml` after the `seed` service and before `volumes:`:

```yaml
  backup:
    image: ghcr.io/club-vanta/alter-tracker-backend-backup:latest
    pull_policy: always
    restart: unless-stopped
    environment:
      DATABASE_URL: postgresql://${DB_USER}:${DB_PASSWORD}@db:5432/alter_event_tracker
      BACKUP_BUCKET: alter-tracker-backend-db-backups-784421200272
      AWS_DEFAULT_REGION: us-east-1
    depends_on:
      db:
        condition: service_healthy
    logging:
      driver: awslogs
      options:
        awslogs-region: us-east-1
        awslogs-group: /alter-tracker-backend
        awslogs-stream: backup
```

Note: `DATABASE_URL` uses `postgresql://` (not `postgresql+psycopg://`) — this is the format `pg_dump` expects.

### Task 4: Update CD workflow to build and push the backup image

**Files:**
- Modify: `.github/workflows/cd.yml`

- [ ] **Step 1: Add `build-and-push-backup` job**

Append the following job to `.github/workflows/cd.yml` after the existing `build-and-push` job:

```yaml
  build-and-push-backup:
    name: Build and push backup image
    runs-on: ubuntu-latest

    permissions:
      contents: read
      packages: write

    steps:
      - uses: actions/checkout@v4

      - name: Set up QEMU
        uses: docker/setup-qemu-action@v3

      - name: Set up Docker Buildx
        uses: docker/setup-buildx-action@v3

      - name: Log in to GHCR
        uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}

      - name: Extract image metadata
        id: meta
        uses: docker/metadata-action@v5
        with:
          images: ghcr.io/club-vanta/alter-tracker-backend-backup
          tags: |
            type=raw,value=latest,enable={{is_default_branch}}
            type=sha,prefix=sha-,format=short

      - name: Build and push
        uses: docker/build-push-action@v6
        with:
          context: docker/backup
          platforms: linux/arm64
          push: true
          tags: ${{ steps.meta.outputs.tags }}
          labels: ${{ steps.meta.outputs.labels }}
          cache-from: type=gha
          cache-to: type=gha,mode=max
```

- [ ] **Step 2: Commit**

